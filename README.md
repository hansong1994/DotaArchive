# Dota Archive

用于查询、下载和测试 Dota 2 历史客户端的 Windows 图形界面工具。可以输入北京时间或补丁号，选择该时间基准之前或之后的最近版本，由软件还原所需的 Depot 和 Manifest，不必逐个查找编号。

项目基于 [SteamRE/DepotDownloader](https://github.com/SteamRE/DepotDownloader)，包含适用于历史 Depot 的引擎修改。它不是 Valve、Steam 或 SteamDB 的官方软件。

**[下载最新版本](https://github.com/hansong1994/DotaArchive/releases/latest) · [中文使用教程](docs/USER-GUIDE.md) · [源码构建说明](docs/BUILD.md)**

## 下载和运行

1. 打开上面的下载页面，在 **Assets** 中下载 `DotaArchive-1.0.8-win-x64.zip`。GitHub 自动提供的 `Source code` 仅是源码，不是可以直接运行的软件。
2. 完整解压到英文路径，例如 `D:\DotaArchive`。
3. 双击 `DotaArchive.exe`。游戏保存位置也请选择英文路径，例如 `D:\DotaArchiveClients`。

需要 Windows 10/11 64 位、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。下载引擎和历史数据库已经包含在发布包内；普通用户不需要安装开发工具或使用命令行。

## 功能

- 按北京时间或补丁号查询，可选择“此前最近版本”或“此后最近版本”。
- 优先使用本地连续历史还原完整 Depot/Manifest 组合，保留未发生变化的 Depot。
- 补丁号查询先读取内置补丁日期，再进行本地时间匹配，全程不查询 SteamDB。
- 支持 Steam 扫码授权、手动刷新二维码、下载进度、停止和恢复下载。
- 不同客户端分目录保存，支持完整文件校验和本地测试启动。
- 点击“更新版本资料”后，在内置浏览器中手动完成 SteamDB 登录和验证，再增量更新历史数据库。
- 对检测到的旧版 ICU 52 冲突提供启动兼容处理，保留原文件备份。

## 查询规则

| 选择 | 匹配规则 |
| --- | --- |
| 此前最近版本 | 严格早于查询基准的最近一次公开更新 |
| 此后最近版本 | 严格晚于查询基准的最近一次公开更新 |

恰好等于基准时刻的记录不包含在内。时间输入固定按北京时间（UTC+8）解释。

补丁号使用内置公告时间作为基准；资料只有日期时，使用目录记录的该日起点，并显示时区和精度说明。**补丁号是查询基准，不保证结果就是该补丁首发客户端；前后查询可能返回相邻补丁的客户端。** 请以结果中的 Build、实际时间和说明为准。

时间查询在本地覆盖不足时可能需要 SteamDB；补丁号查询遇到未收录、日期冲突或覆盖不足时会直接提示，不会自动打开 SteamDB。

## 数据范围和限制

1.0.8 发布包包含 **4415 条连续历史记录、164 条补丁日期**。历史最早记录为 UTC `2013-02-02 00:36:52`，资料核实至北京时间 `2026-10-22 10:48:51`；这是数据截止时间，并不表示每一秒都有版本。精确来源见发布包的 `data/catalog-provenance.json`。

“更新版本资料”更新历史构建记录；内置补丁日期表随软件新版分发。新补丁未进入日期表时，可以更新历史资料后按时间查询。

本地清单完整，不代表 Steam 仍提供对应历史文件，也不代表客户端一定能在当前系统运行。部分早期版本仍可能在 Steam 授权、密钥或 Manifest 获取阶段失败。本工具不保证所有历史版本均可下载，也不保证旧客户端能够连接当前正式服务器。
