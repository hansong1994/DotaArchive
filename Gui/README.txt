Dota Archive 1.0.8 | Windows x64

本版更新
- 版本号查询现在也支持“此前最近版本”和“此后最近版本”。先把版本号转换为内置公告时间或日期起点，再按所选方向查询本地历史；严格排除恰好相等的时刻。
- 版本号方向查询不再限制在公告前后 24 小时或当天日期窗口内；只要本地连续证据覆盖，便可匹配所选方向最近的公开更新。已有首发证据不会覆盖用户选择的方向。
- 修复部分旧客户端启动时 ICU 52 动态库与新版 Windows 同名模块冲突的问题。点击“启动本地测试”时自动检查并应用兼容处理，仅调整已核实的旧客户端引擎库引用，并从同一版本原文件生成独立命名的 icu52.dll。
- 兼容处理前的原文件保存在版本目录的 _compatibility/icu52/originals 下，并记录原始与修复后校验值。完整文件校验能够识别这些确定性修改并同时核对原件备份；游戏内容和 Windows 系统文件不修改。
- 恢复已有下载时，优先使用原下载对应的完整本地 Manifest 集合；已有完整清单的客户端可先离线执行完整文件校验，无需重新登录 Steam。
- 版本号查询全程离线。有公告时间时以公告时间为参照；只有日期时以目录记录的该日起点为参照，并显示时区与精度说明。这一日期约定不代表已核实的客户端首发时刻。
- 新增随包附带的官方补丁日期目录、来源文件及校验记录。未收录或证据不足的版本不会自动打开 SteamDB，也不会猜测 Build。
- 下载失败时，主界面统一显示“此版本因未定义的错误无法下载”。具体底层原因继续保留在任务记录和诊断记录中，便于排查。
- 保留历史 Depot 已从当前 AppInfo 移除时的兼容修复。使用修改版引擎 3.4.0-history.1+c553ef4，仅对完整历史计划启用兼容模式，仍执行 Steam 的账户、Depot 密钥、Manifest 和 CDN 授权检查。
- 保留 1.0.2 对 2013-07-16 以前版本的历史配置还原修复，以及逐 Depot 分类、完整性和连续性检查；没有加入手工 Build、Depot 或 Manifest 映射。
- 时间和版本号查询均支持“此前最近版本”和“此后最近版本”；以版本号日期定位的结果不保证就是该补丁首发，选择“此前”时尤其可能返回前一个补丁的客户端。

已核实的限制
- 1.0.6 的既有兼容验证中，7.01 / Build 1532815 经兼容处理后已进入主菜单并载入本地机器人地图，4889 个清单文件、原版备份和私有 ICU 副本均校验通过。实际移动与施法仍待完成 Windows 防火墙提示的人工关闭后继续核实；不能将启动成功等同于完整对局测试通过。这份历史验证不代表 1.0.8 再次执行了游戏下载或对局测试，详细范围见 verification/client701-runtime-validation.json。
- Build 41055 的实测已通过 Steam 登录，并到达真实 Depot 密钥请求；Steam 对 Depot 571 / App 570 返回 FileNotFound，未返回密钥。
- 该次测试尚未取得 Manifest、下载客户端或验证启动及本地对局。本版不能宣称 Build 41055 已可下载；完整历史组合可查询，不等于 Steam 仍提供对应文件。
- FileNotFound 在此处是 Steam 对密钥请求的回复，不是本机缺文件，也不足以证明全部历史版本或历史文件永久失效。

使用方法
1. 将整个压缩包解压到英文路径，例如 D:\DotaArchive。不要仅复制 EXE，也不要直接在 ZIP 中运行。
2. 双击 DotaArchive.exe。已随附完整历史数据库，不需要 Codex、开发环境或命令行。
3. 选择“北京时间”或“版本号”，再选择“此前最近版本”或“此后最近版本”。时间查询以输入时刻为参照；版本号查询以内置公告时间为参照，只有日期时采用目录记录的该日起点。两种方式均匹配严格早于或严格晚于参照时刻的最近公开版本，恰好等于该时刻的版本不包含在内。默认仍为“此前最近版本”；请查看结果中显示的参照时间、方向和来源精度。
4. 确认结果后选择英文保存目录，按界面提示登录 Steam、准备清单并下载。不同版本独立保存。
5. 点击“更新版本资料”，在内置浏览器完成 SteamDB 登录或验证，再点“已完成验证，继续”。软件校验新增记录后才发布新历史数据库。此按钮只更新历史记录；内置补丁日期目录随软件新版更新。
6. 已下载的旧客户端报 ICU 52 入口点或模块加载错误时，请用本版“恢复已有下载”打开原版本目录，再点击“启动本地测试”。兼容处理仅用于检测到的受影响库；已有兼容备份请保留，后续完整校验需要使用它们。

内置数据
- 随附从 2013-02-02 最早记录开始的完整连续历史，以及发布时已成功同步的最新代。
- 精确记录数、最新 Build 与核实截止时间见 data/catalog-provenance.json；主界面也会显示资料覆盖时间。
- 包内 data/history、data/latest-sync、data/patch-evidence 和 data/patch-dates 用于离线匹配，不能单独删除。
- data/patch-dates/patch-release-catalog.json 保存 Valve 与国服官方发布方的补丁日期和公告来源，并保留日期精度和时区，不含手工填写的 Build、Depot 或 Manifest 映射。公告时间不等于客户端实际发布时刻；早期小版本存在缺项，目录不代表全部版本均可查询。
- 当前收录 164 条日期记录。6.84、6.86、6.87 因正式发布日期证据不足保留为未解决项，详见目录的 UnresolvedPatches；记录有歧义的版本也不会强行匹配。来源未注明时区的日期使用该日 UTC 零点作为查询约定，不代表已核实的首发时刻。
- 6.88c 的官方日期资料存在冲突，版本号查询会明确提示，不能强行选取一条日期；可改用时间节点查询。没有当天更新的补丁不再因原有日期窗口限制而直接失败，仍须符合所选方向及本地证据覆盖条件。
- 版本号查询不会发起 SteamDB 请求。目录中没有的版本会提示本地资料不足；时间查询仍可使用已经覆盖的连续历史。
- 若“此后最近版本”超出本地已核实资料范围，软件不会拿更早版本替代。请先更新版本资料；如果所选时刻之后尚无更新，则没有可匹配的后续版本。
- 这些是经过完整回放校验的公开历史资料，不代表所有历史文件仍可从 Steam 下载，也不代表所有旧客户端均已运行测试。

运行环境
- Windows 10/11 64 位、.NET Framework 4.8、Microsoft Edge WebView2 Evergreen Runtime。
- 下载引擎已随附，不需要另外安装现代 .NET SDK/Runtime。
- 程序不会静默安装运行库。若缺少 WebView2，请从微软官网下载并手动安装：
  https://developer.microsoft.com/microsoft-edge/webview2/
- .NET Framework 4.8 官方下载： https://dotnet.microsoft.com/download/dotnet-framework/net48

数据与隐私
- 用户登录资料及之后的同步结果保存在当前 Windows 用户的 LocalAppData/DotaArchive/BrowserPrototype 下。
- 更新程序时请完整解压到新目录；新包不会覆盖用户已有的更新数据库、登录资料或已下载客户端。
- 此发布包没有打包任何 Steam 登录状态、浏览器 profile、账号令牌或下载日志。
- SteamDB 验证和 Steam 下载授权分别按界面完成，软件不会代答验证码。
- 未启用定时抓取或自动下载。发生 HTTP 403/429 时停止该次查询并遵守等待要求。
